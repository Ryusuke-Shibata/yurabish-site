## 🚀 Quartz ＋ Obsidian でつくる「第二の脳」環境構築ログ

Obsidianで書いたメモを Quartz で静的サイト化し、Cloudflare Pages で公開する環境を構築した時のメモ。

### 1. 使用しているスタック

- **エディタ**: Obsidian（ローカルでMarkdown執筆）
- **SSG**: Quartz v4（MarkdownをHTMLに自動変換）
- **ホスティング**: Cloudflare Pages
- **バージョン管理**: GitHub ＋ GitHub Desktop
- **デザイン**: Custom SCSS（ポップ・ブルータル風デザイン）

### 2. デザイン・カスタマイズのこだわり

- `.yaml` の設定を最小限にして、テーマカラーや装飾はすべて `custom.scss` 側に集約。
- **カラーテーマ**: レトロミッドセンチュリー（レトロオレンジ `--secondary` ＆ セージグリーン `--tertiary`）。
- **レイアウト**: 左サイドバーに「エクスプローラー」「目次」「グラフ」を集約した2カラムダッシュボード構成。
- **ポップ・ブルータル調**: 2pxの太枠（border）とくっきりした影（box-shadow）でカード風に装飾。

### 3. 今後の運用ルール

- 公開したくない秘密メモは `content/private/` フォルダに入れるか、フロントマターに `draft: true` を記述する。
- 画像は `content/image/` に自動保存される設定にし、パブリック前提の画像のみ扱う。
- 完成度20%の未完成メモでも、気楽にPushして「おもちゃ箱」を育てていく！
