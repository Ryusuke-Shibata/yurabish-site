# Sairy Hub

本サイトのテーマは**おもちゃ箱**です。

日々の学びや作ったもの、遊んだゲームの記録やくだらない思考を、好き勝手に放り投げています。

整頓されたデータベースではありませんが、宝探し感覚で遊んでいってください。

---

## 🧰 おもちゃ箱の中身（カテゴリ）

- 📝 **[[Study/index|学習メモ]]**
  資格取得の勉強記録、新しく得た知識、インプットした情報の要約。
- 🎮 **[[Game/index|ゲーム]]**
  プレイしたゲームのログ・感想、攻略メモ。
- 🛠️ **[[Tech/index|開発・ツール]]**
  サイト制作ログ、AI活用法、ガジェットや作業環境の備忘録。
- ☕ **[[Notes/index|雑記・思考]]**
  日常のちょっとした出来事や、頭の中でぐるぐる考えたこと。

## 🔍 ノートの探し方

- 左側の **エクスプローラー** や **検索（Ctrl + K）** から自由に探索できます。
- 気になった単語（`[[ ]]` の太字リンク）を辿っていくと、別のノートへワープできます。
